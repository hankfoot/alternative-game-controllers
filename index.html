Workshop

Turn Anything into a Game Controller

originally designed by Avi Romanoff (@aviromanoff) and Hank Duhaime (@schmardware)

What if a pair of scissors, a stuffed animal, or your own voice could control a video game? In this hands-on workshop, you'll work in teams to build delightfully ridiculous new ways to play a classic video game.

Workshop slides ↗

Set up your micro:bit

  1. 1

    Grab a micro:bit v2

    You'll need a micro:bit v2 and a USB cable. A battery pack is handy once you unplug from the computer.

  2. 2

    Prepare your clips and foil

    Everything you build is foil and crocodile clips. Tear off a few 5 cm squares of foil and one long strip, and take four clips. A clip grabs the gold pads along the bottom of the board: P0, P1 and P2 are the inputs, 3V is power and GND is ground.

    Two rules. Never let a clip on 3V touch one on GND — the board resets. And clip the foil on before you connect to the game, so a touch pad can learn what untouched feels like.

  3. 3

    Set up MakeCode

    Open the blank starter project in MakeCode, then click Edit Code in the top right. This file already has Bluetooth settings pre-configured, so make sure to work from here. You should see an interface like the one below.

  4. 4

    Copy the starter code

    Switch to the JavaScript tab at the top of the page and paste this code into the editor: 

    bluetooth.startUartService()
let connected = false
bluetooth.onBluetoothConnected(function () {
    connected = true
})
bluetooth.onBluetoothDisconnected(function () {
    connected = false
})
basic.forever(function () {
    if (connected) {
        basic.showIcon(IconNames.Yes)
    } else {
        basic.showString(control.deviceName())
    }
})
  5. 5

    Flash code to your micro:bit

    Your micro:bit must be plugged into your computer to receive new code. Plug the micro:bit in over USB, then click Download in the bottom right of the MakeCode editor. If this is your first time downloading, follow the pop-up instructions to pair your board to your browser.


    A red light on the back of the board will blink while it copies code, then stop when it's done.

  6. +

    Go cordless Optional

    Once the code is flashed it stays on the board, so if you're done iterating you can unplug the USB cable and run the micro:bit off a battery pack instead — handy for building a controller you can pick up and move around.

  7. 6

    Find your micro:bit's name

    Every micro:bit has a unique five-letter Bluetooth name and shows up as BBC micro:bit [·····] (five letters of its own). Your board is now scrolling that five-letter code across the LEDs — note yours so you can spot it in a room full of boards.

Sense the world

Four small programs, one idea each. Paste one into MakeCode, download it, press Connect up top, and watch the reading arrive underneath. By the end you will have made a touch pad, a switch, a dial, and a clap detector.

Connecting to your board

Press Connect. In the browser's Bluetooth list, choose the BBC micro:bit [·····] that matches the five letters your board scrolled. It will show a checkmark, and the top bar will swap Connect for your board's name.

Your board needs its own power for this — a battery pack, or the USB cable just for the electricity. Refreshing this page means pairing again.

Wire up your controls

One sidescroller, four ways to fly it — tap to rise, hold to rise, hold to slide, or steer directly. Pick a scheme, and its controls are what your inputs get wired to. Each scheme keeps its own wiring, and the keys and on-screen buttons always remain available.

Wire your controller

Each input lists what it can do. A Level port takes a whole range; a Hold port takes an on/off that stays on while something is true; a Trigger port fires at an instant.

Code it

Want something the wires can't say — every third clap, the height of a chair, two readings combined? Describe it to an AI, paste what it writes into your MakeCode program, and your board drives the game directly. Nothing runs in this page; the code runs on the micro:bit.

  1. 1

    Say what you want, and copy it for your AI

    Describe the interaction in a sentence. The copy comes with everything the AI needs to know — the game's controls by name, the functions your program already has, and what it already reads — so paste it into any chat and it writes the code.

    What gets copied
  2. 2

    Paste what it wrote into MakeCode

    Open your project in MakeCode, switch to the JavaScript tab, and paste the code at the very bottom, below the code you copied from Sensing. Then Download to the board as before. If MakeCode underlines something in red, paste the error back to your AI.

  3. 3

    Connect and play

    Press Connect at the top. Every command your board sends shows up here, and the game follows them — no wiring needed for these.
