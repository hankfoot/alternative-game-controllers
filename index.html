    Alternative Game Controllers

    originally designed by Avi Romanoff (@aviromanoff) and Hank Duhaime (@schmardware)

    What if a pair of scissors, a stuffed animal, or your own voice could control a video game? In this hands-on workshop, you'll work in teams to build delightfully ridiculous new ways to play a classic video game.

    Workshop slides ↗

    Set up your micro:bit

    1. 1

      Get a micro:bit

      You need a micro:bit V2 and a USB cable. A battery pack lets you unplug it from the computer later.

    2. 2

      Gather your materials

      Your controller is built from everyday things. Grab a few from each group, and pick objects you can open, squeeze, swing or shout at. The stranger the better.

      🧲 Things that conduct electricity

      For buttons, switches and touch pads.

      • Aluminium foil or copper tape
      • Coins, keys, spoons or paper clips
      • Fruit and vegetables, like bananas
      • Play-Doh or a damp sponge
      • A thick pencil line on paper

      ✂️ Things to build with

      For holding it all together.

      • Alligator clips, at least three
      • Cardboard
      • Tape, string and rubber bands
      • Scissors
      • A battery pack for the micro:bit

      🧸 Something to turn into a controller

      Anything you can move, open or make noise with.

      • A stuffed animal or a hat
      • A jar with a lid, or a box
      • A pair of scissors or tongs
      • A maraca, a cup of beans, a drum
      • A chair, a door or a drawer
    3. 3

      Get to know the pins

      The gold strips along the bottom edge of the micro:bit are called pins. You connect things to them with alligator clips. The micro:bit reads from P0, P1 and P2. 3V supplies power, and GND, short for ground, is where the electricity returns.

      Never let a clip on 3V touch a clip on GND. That makes the micro:bit restart.

    4. 4

      Open MakeCode

      MakeCode is the website where you write code for the micro:bit. Open the starter project, then click Edit Code in the top right. It opens with no code in it, and that is expected. What it does have is Bluetooth already switched on, which is why you always start from this project.

    5. 5

      Copy the starter code

      Click JavaScript at the top of the editor, click into the empty editor, and paste in this code (⌘ V on a Mac, Ctrl V on Windows or a Chromebook). It turns on Bluetooth and uses the micro:bit’s lights to show whether it is connected.

    6. 6

      Upload the code

      Plug the micro:bit into your computer with the USB cable, then click Download in the bottom left of MakeCode. The first time, a window asks to pair with the micro:bit, so follow its steps.

      On a Mac, a box may pop up asking “Allow accessory to connect?” when you plug the micro:bit in. Click Allow, or the micro:bit won’t show up.

      A light on the back of the micro:bit blinks while the code copies over, and stops when it is done.

    7. 7

      Connect to your micro:bit

      While the micro:bit waits to connect, it shows an X, a Bluetooth symbol, and its name, which is five letters long. Every micro:bit has a different name, so make a note of yours.

      Click Connect at the top of this page, choose BBC micro:bit with your micro:bit’s name, and click Pair. The micro:bit shows a smiley face when it connects.

      You use this Connect button for every example from now on. If you reload this page, you need to connect again.

    8. +

      Go cordless Optional

      The code stays on the micro:bit after you unplug it. Plug in a battery pack instead of the USB cable and you can move your controller around freely.

    Build your controller

    Now you decide how your micro:bit controls the game. Choose how the character moves and what makes it move, and this page writes the code. Then put the code on your micro:bit, hook it up, and watch it work, tweaking the numbers if it needs it.

      Choose how it moves

    2. 2

      Choose what triggers each control

      Pick an input for each control. Any numbers start at a sensible guess, and you can tweak them in step 5 once you can see the readings.

    3. 3

      Copy the code to your micro:bit

      Copy the code. In MakeCode’s JavaScript tab, select everything (⌘ A, or Ctrl A on Windows), paste over it (⌘ V or Ctrl V), and click Download. Any time you change a control or a number, copy and download again.

    4. 4

      Hook up your controller

      What to connect for the controls you chose, and how to use each one.

    5. 5

      Test it and tweak it

      Connect the micro:bit and try each control. Its reading appears live, with the number it has to cross drawn on it. If it triggers too easily or not at all, change the number, then copy and download the code again.

    Code it

    If you want something these controls can’t do, like flapping every third clap, you can ask an AI chatbot to write the code. It still runs on the micro:bit, just like the code above.

    1. 1

      Describe what you want

      Write one sentence about what should happen, then click the button. It copies your sentence along with instructions that explain this game to the AI. Paste it into any AI chatbot.

      See what gets copied
    2. 2

      Add the code to MakeCode

      In MakeCode’s JavaScript tab, paste the AI’s code at the very bottom, below the code from step 3 above, and click Download. Then wire it up the way the AI’s Hookup guide says. If MakeCode shows an error in red, copy it back into the chatbot and ask it to fix the code.

    3. 3

      Connect and play

      Click Connect at the top of this page. Everything your micro:bit tells the game appears below.
